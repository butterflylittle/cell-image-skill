# Example Playbooks

## Example A — pH-responsive nanoparticle chemo-immunotherapy closed loop

Core conclusion:
pH-responsive nanoparticles enable tumor-targeted acidic release, induce chemotherapy-mediated tumor-cell death, release tumor antigens, and synergize with checkpoint blockade to activate T-cell killing.

Hero:
acid-triggered release → tumor death → antigen release → T-cell killing

Zones:
1. top: materials self-assembly → pH-responsive nanoparticle → tumor targeting
2. middle: uptake → acidic endosome → release → chemotherapy → apoptosis
3. bottom: antigen release → PD-1/PD-L1 blockade → T-cell activation → tumor killing

Evidence caution:
“complete loop” may be a communication loop unless the study demonstrates a true biological positive-feedback mechanism.

SVG delivery:
`hybrid_editable`; nanoparticle/cell illustrations may be local raster assets, but all text and mechanism arrows are editable SVG objects.

## Example B — Vitamin D/VDR → miR-27a/b in OLP

Core conclusion:
Inflammatory stimuli are associated with reduced miR-27a/b in HOKs, while vitamin D/VDR promoter binding induces miR-27a/b and rescues the reduction.

Hero:
VDR binds miR-27a/b promoter → miR-27a/b ↑

Support:
LPS / activated CD4+ T-cell stimulation → miR-27a/b ↓

Validation:
patient oral biopsy / serum / saliva; mouse oral epithelium.

## Example D — anatomy-to-microstructure exchange interface

Layout profile: `biomed_portrait_a4`

Hero:
central exchange microstructure, not the macro anatomy.

Structure:
1. header + macro anatomy
2. dashed zoom into tissue interface
3. central microstructure hero
4. sidebars for immune/transport mechanisms
5. bottom detail insets for barrier thickness / microvilli / special structures

Color:
paired warm/cool blood or transport colors; low-saturation tissue background; black labels.

Density:
D3 acceptable for review/educational atlas; reduce to D1–D2 for a main manuscript figure.

## Example G — cardiomyocyte excitation-contraction explainer

Layout profile: `biomed_landscape_16x9`
Archetype: `educational_explainer + horizontal_causal_pathway`

Hero:
full cardiomyocyte spatial context plus Ca²⁺ signaling path.

Steps:
action potential → L-type Ca²⁺ influx → CICR from SR → troponin activation → actin-myosin cross-bridge cycle → synchronized shortening.

Color:
Ca²⁺ cyan/blue; electrical signal amber; cardiomyocyte pink; SR lavender. Keep these identities constant.

Submission adaptation:
remove large educational title and step-card backgrounds, reduce labels to D1–D2, keep the mechanism only.

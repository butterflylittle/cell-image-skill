# Scientific QA Checklist

任何机制图交付前逐项核对。

## A. Entity
- [ ] 每个细胞/分子/材料来自原文或必要通用语境
- [ ] 名称准确
- [ ] 缩写准确
- [ ] WT/KO/Drug/Control 等组别准确
- [ ] 没有生成不存在的受体/通路

## B. Relations
- [ ] 每条箭头可在原文中找到依据
- [ ] activation 与 inhibition 方向正确
- [ ] transport/translocation/secretion 没画成 activation
- [ ] association 没升级为 causation
- [ ] rescue 没被过度解释为 direct binding
- [ ] feedback loop 真的有反馈依据，或明确只是 narrative loop

## C. Spatial biology
- [ ] receptor 所在位置合理
- [ ] nucleus / cytosol / membrane 位置合理
- [ ] DNA/promoter 位于核内
- [ ] payload release 场景合理
- [ ] immune checkpoint receptor-ligand 位点合理

## D. Evidence
- [ ] 患者样本/动物/细胞实验层级没有混淆
- [ ] validation 不冒充 primary mechanism
- [ ] 不生成 p 值、曲线、显著性、组织切片证据
- [ ] 结论强度不超过原文

## E. Final
- [ ] 作者能逐条解释图中每一条箭头的证据来源

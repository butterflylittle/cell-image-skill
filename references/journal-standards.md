# Journal Figure Standards

**Last checked: 2026-09-07. 投稿前必须重新核验目标期刊最新官方 Guide for Authors。**

本文件是“默认出版约束”，不是法律/编辑部承诺。

---

## 1. Nature — main figures

官方 Research Figure Guide 的核心约束：

- 单栏宽：89 mm
- 双栏宽：183 mm
- 最大高度：约 170 mm
- 图中文字：通常 5–7 pt
- 多面板标号：8 pt bold lowercase a, b, c…
- 字体：Arial / Helvetica 等标准 sans-serif
- 文字应保持可编辑，不要 outline
- 避免彩色文字
- 避免 drop shadow
- 避免装饰性图标
- 避免 patterns
- 避免文字压在复杂背景
- 避免文字重叠
- 面板紧凑、减少无意义留白

官方：
https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/
https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/

### Skill 转译
如果用户说“Nature 正文图”：
- 不使用海报式大标题
- 不使用厚重阴影/3D 卡片
- 先按最终 183 mm 或 89 mm 尺寸测试
- 生物机制图也应更扁平、更克制

## 2. The Lancet

The Lancet 官方 artwork guideline：

- 图会由内部插画团队按 Lancet 风格重绘
- 作者应提供清晰、高质量、可编辑原始图件
- 能用 2D 就避免 3D graph
- 线条应高对比、可区分
- vector 首选：EPS / PS / PDF / SVG；AI 也有价值
- 不要把 PNG/JPEG 另存为 PDF/EPS 冒充矢量
- 照片/MRI 等位图约 300 dpi
- serial graphs 应保持一致坐标尺度
- forest plot / trial profile 有其专用风格

官方：
https://www.lancet.com/pb/assets/raw/Lancet/authors/artwork-guidelines.pdf

### Skill 转译
Lancet 模式强调：
**清楚、可重绘、少 3D、强线条语义、可编辑源文件**。

## 3. Cell Press — Graphical Abstract baseline

Cell Press Graphical Abstract 指南/官方 CrossTalk 基线：

- single-panel
- square
- 常见基线：1200 px square / 300 dpi
- 旧版技术规范也给出约 5.5 inch square at 300 dpi
- Arial
- 12–16 pt
- 清晰 start/end
- top-to-bottom 或 left-to-right
- simple labels
- text sparingly
- 强调一个 process / point
- 不塞 data items
- 避免过度饱和原色和拥挤

官方：
https://crosstalk.cell.com/hubfs/Files/GA_guide.pdf
https://crosstalk.cell.com/blog/attract-readers-at-a-glance-with-your-graphical-abstract

### 注意
不同 Cell Press 期刊可能有更具体要求，必须再核验对应期刊。

## 4. Elsevier — generic artwork

Elsevier 通用 artwork：

- preferred RGB for color artwork
- halftone/photos：最低约 300 dpi
- combination art：约 500 dpi
- line art：约 1000 dpi
- 常见最终宽度基线：
  - 90 mm single column
  - 140 mm 1.5 column
  - 190 mm double column
- 推荐标准字体，嵌入字体
- 需要色盲可访问性
- figure captions 通常独立于图片提交
- 不允许不当图片操纵

官方：
https://www.elsevier.com/about/policies-and-standards/author/artwork-and-media-instructions
https://www.elsevier.com/about/policies-and-standards/author/artwork-and-media-instructions/artwork-sizing
https://www.elsevier.com/about/policies-and-standards/author/artwork-and-media-instructions/artwork-types

## 5. Science / AAAS-style baseline

Science Partner Journal 的官方 figure guidance 可作为 AAAS 风格参考基线：

- illustration/diagram：PDF/EPS 优先
- photo/microscopy：TIFF/JPEG/PNG/PSD/PDF 等
- bitmap 至少 300 dpi
- figure title 放 legend，不放图内
- 尽量减少白边和 clutter
- symbol >= 6 pt
- line width >= 0.5 pt
- panel 紧凑
- 不重复公共 axis labels
- microscopy 必须有 scale bar
- 避免 red-green 配色
- 避免彩色文字

示例官方：
https://spj.science.org/page/ultrafastscience/for-authors

**注意：这不是 flagship Science 的完整唯一标准；投稿 Science 时必须核对具体 AAAS 官方投稿指南。**

## 6. 中国基金/课题活页 profile

非期刊官方标准，作为本 Skill 的工程默认：

- A4 页面插图宽：约 160–175 mm
- 矢量优先
- 中文标签 8.5–10.5 pt
- 模块标题 10.5–12 pt
- 最小尽量不低于 7.5–8 pt
- 白底
- 结构清晰、黑白打印仍可理解
- 不用期刊式 5 pt 小字套到中文课题图

## 7. 标准冲突处理

当“美观”与“目标期刊尺寸/可读性”冲突：

**期刊最终版面 > 屏幕预览效果。**

当“BioRender 质感”与 Nature 正文规范冲突：

**减少阴影/渐变/装饰，保留科学实体语义。**

## 8. Nature accessibility color rule — 2026-09-07 recheck

Nature Research Figure Guide 明确要求可访问配色：
- 避免 red/green 作为唯一颜色编码
- 避免 rainbow scales
- 优先高对比文字，通常使用黑/白文字
- 颜色意义最好在图内通过 key/keyline 明确，而不是只在 caption 中用颜色文字描述
- Nature.com 尽可能遵循 WCAG 2.1 AA

可参考 Nature guide / Okabe-Ito 兼容色：
`#E69F00`, `#56B4E9`, `#009E73`, `#F0E442`, `#0072B2`, `#D55E00`, `#CC79A7`, `#000000`。

官方：
https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/
https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/

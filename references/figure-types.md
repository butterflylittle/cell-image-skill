# Figure Type Masters

## mechanism
用途：解释“为什么/如何发生”。

结构：
- upstream trigger
- core mechanism
- downstream effect
- validation

推荐：
- causal chain
- central hub
- spatial zoom
- before/after
- closed loop

## closed_loop
用途：协同机制、反馈、自增强治疗或治理闭环。

必须明确：
- loop 的返回点是什么
- 是真正生物反馈，还是“治疗协同叙事”
- 不得把概念上的闭环误画成已证实的动态反馈

## graphical_abstract
用途：一图抓住 take-home message。

规则：
- 一个主结论
- 单面板
- 左→右或上→下清晰阅读
- 少文字
- context → mechanism → outcome
- 不塞完整 Results
- 不虚构数据

## technical_route
用途：研究步骤、方法与验证。

结构：
问题/输入 → 方法 → 分析 → 验证 → 输出

禁止：
把方法流程画成生物机制。

## research_framework
用途：教育/社科/基金课题框架。

结构候选：
- 中心主题 + 周围模块
- 上中下：驱动→机制→路径
- 五维轮
- 多层治理
- 理论→机制→路径

## experimental_setup
用途：实验装置或系统组件。

必须：
真实部件、流向、信号、采集路径。

禁止：
虚构设备参数、管路、传感器。

## comparison
用途：Control/Treatment、WT/KO、Before/After。

必须：
统一视角、统一尺度、统一颜色语义。

## multiscale_zoom
用途：
器官 → 组织 → 细胞 → 分子
材料宏观 → 界面 → 分子/晶格
